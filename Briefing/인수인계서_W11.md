## 0. 협업 방식 (반드시 지킬 것)

- **말투:** 사용자는 반말을 쓴 적이 없습니다. Claude는 평소처럼 존댓말로 답합니다. 인수인계서에 "반말 사용" 같은 내용을 넣지 않습니다.
- **투명성:** 사용자가 모르는 사이에 무언가를 설치하거나 실행하는 것을 싫어합니다. 명령은 무엇을 하는지 설명하고, 단순하고 되돌릴 수 있는 방법을 우선합니다. (예: git 기록 정리 때 filter-repo 대신 "원격 저장소 삭제 → 로컬 git init → 새 비공개 저장소"를 선택함)
- **발표 자료 취향:** 결과 중심, 고급스러운 문장, 표는 자세하고 혼자 읽어도 이해되게, 슬라이드마다 주제를 시각적으로 표시(상단 내비게이션 pill). 매주 형식은 "지난주 계획 → 이번 주 한 일 → 다음 주 계획".
- **청중 수준:** 학생 질문이 엉뚱한 편입니다(예: "협곡 수집 중" → "증강 칼바람은요?"). 교수님도 숫자만 보면 이해를 어려워해서, 원리를 비유(시험 공부하는 학생)로 설명하는 게 효과적이었습니다.
- **용어:** 템트리 추천은 학습이 아니라 집계입니다. "AI가 학습한 추천"이라고 쓰지 않고 "데이터 기반 템트리 추천", "집계"라고 씁니다. 직접 학습시키는 AI는 MiniGPT입니다.
- **보안:** `.env`(Riot API 키), `data/raw/riot/`, `seed_puuids.json`은 절대 커밋하지 않습니다. 키 내용을 채팅에 붙여 달라고 하지 않습니다.
- 수업은 인공지능 수업이라 **AI 만들기(MiniGPT)가 사실상 핵심**입니다.

## 1. 프로젝트 개요

- **팀/과제:** 기미히끼잉(GameHikking), 인공지능 수업 12주 프로젝트. 현재 **11주차**.
- **서비스:** 리그 오브 레전드 RAG 공략 챗봇 (Streamlit `app.py`)
  - 패치 노트·챔피언·아이템 검색 (Chroma `gamehikking_v2`, 임베딩 `distiluse-base-multilingual-cased-v1`, cosine)
  - 질문 해석: 챔피언/패치/스킬 슬롯/의도, 별명(마이, 몰왕, 존야 등), 영문 이름, 스킬 이름→슬롯, 약어(쿨→재사용 대기시간), 최신 변경 패치 규칙
  - 근거 선택은 규칙 기반 `select_line()` (MiniGPT를 끼울 수 있는 `set_selector()` 연결 지점 있음)
  - **템트리 추천** (10주차 완성): `src/rag/recommend.py`
- **연구 트랙:** MiniGPT (직접 구현한 작은 GPT)로 "이 문장이 질문의 근거인가" 판별

### 매치 데이터 (Riot API)
- 시드: League-V4 챌린저 300 + 그랜드마스터 700 + 마스터 10,000 = 11,000명

- 개발용 키: 2분에 100회, 24시간마다 만료. 요청 간격 1.3초, 429면 Retry-After 대기
- 개인정보(소환사명, Riot ID 등) 필드는 제거 후 저장
- **수집은 윈도우 PC에서 진행 중** (맥 디스크 부족). 마지막 보고(11/19): `새 매치 2650개 (총 22066) | 시드 1044/11000`
  - 실행: `py -3.10 src\data\collect_matches.py --max 50000 --days 14 --seed-start <N>`
  - 재시작 시 마지막 "시드 N"을 `--seed-start N`으로. 이미 받은 경기는 자동으로 건너뜀
  - 같은 키로 두 컴퓨터에서 동시에 돌리지 않기
  - 동기화: 윈도우의 `participants.jsonl`을 맥으로 복사 → `aggregate_matches.py` 재실행
- **집계 결과 (10주차 발표 기준):** 12,457경기, 선수 기록 124,570건, 패치 16.21~16.22, 챔피언×포지션 357, 173명 전원, 맞대결 3,034개
  - 기준: MIN_GAMES 20, MIN_MATCHUP 10, TOP_ITEMS 8
  - 예: 나서스 탑 228경기 52.2% (삼위일체 54%, 얼어붙은 심장 36%, 정령의 형상 33%, 아이오니아 장화 56%), 다리우스 탑 474경기 (스테락 34%, 판금 장화 56%)

## 5. MiniGPT 실험 기록 (핵심)

### 과제와 지표
- 질문 + 문장 하나 → "근거인가?" (O/X, **근거 판별**, 우연 50%, 손실 0.693 = ln2)
- 문장 4개 중 정답 고르기 (정답 없음 포함, **4지선다**, 우연 20~25%)
- 검증: 챔피언 20명을 학습·사전학습에서 완전히 제외(홀드아웃), 그 20명으로만 시험 (300문항)
- 500회마다 모의고사, 가장 좋은 시점(best) 저장
- 비교 대상: 규칙 기반 94% (K2 94.3%, K4 94.0%)
- **통과 기준 (미리 정함, 변경 금지): 판별 70% 이상 AND 4지선다 50% 이상**

### 결과표
| 실험 | 조건 | 파라미터 | 판별 | 4지선다 | 비고 |
|---|---|---|---|---|---|
| 5c | 사전학습 없음 | 200만 | 53.3% | 25.3% | 우연 수준 |
| 5d | pretrain_v2 (코퍼스 45,598 → 384,210 토큰, 8.4배) | 200만 | 70.8% | 43.3% | 4지선다 미달 |
| **5e** | 5d와 동일, 15,000회 | 200만 (d128/L4/H4) | **84.0%** | **61.3%** | **기준 첫 통과**, 4500회에 급상승. 학습 86%/검증 84% → 과소적합. 능력치 0/17 |
| 6 | pretrain_v3 + sft6 | 7,235,328 (d256/L6/H8) | 67.2% | 38.7% | 기준 미달. 11000회에야 우연 탈출. 학습 77%/검증 67%. 능력치 7/17 |

- pretrain_v2: best 검증 손실 2.4910 @6000 (BLOCK 192, BATCH 32, 8000회, AdamW wd 0.1)
- pretrain_v3: best 2.5824 @2500, 이후 과적합 (학습 0.20 / 검증 3.84)
- sft 공통: LR 3e-4 → 3e-5, 실행 `caffeinate -dims /usr/local/bin/python3.10 src/gpt/experiments/<파일>.py` (맥, mps)

### 결론 (사용자에게 설명함)
- 작은 모델 = 머리 용량 부족(과소적합), 큰 모델 = 교재 부족(과적합). **데이터 없이 모델만 키우면 오히려 나빠짐.**
- **권장: 5e를 최종 MiniGPT로 확정**, 실험 6은 비교 실험으로 보고서에 포함. 서비스는 규칙 기반 유지 (연결 지점은 있음).
- 여유가 있다면: 큰 모델 + 드롭아웃, 또는 중간 크기(d192/L4). 각 약 3시간 소요라 우선순위 낮음.
- 사용자가 실험 6 결론을 아직 확정하지 않았음 → 새 대화에서 확인 필요.

## 6. 진행 중인 일 (11주차)

### A. 파이 서버 배포 (최우선: 10주차 발표에서 "다음 주 실시간 시연" 약속)
- 환경: 라즈베리파이 5, 메모리 7.8GB, Ubuntu 24.04.4 LTS, aarch64, Python 3.12.3, 여유 102GB
- 접속: 클라우드플레어 터널 + 사용자 도메인 `wooki.cloud`. 다른 서비스도 이미 운영 중. 외부 인터넷으로 시연.
- **완료:** 0단계 사양 확인, 1단계 git 클론 + 가상환경 (pip 설치 완료 여부는 미확인)
  - 저장소가 비공개라 토큰 또는 SSH 키 필요 (SSH 권장)
  - 설치: `python3 -m venv .venv` → `pip install torch --index-url https://download.pytorch.org/whl/cpu` → `pip install chromadb sentence-transformers streamlit requests beautifulsoup4`
- **다음:**
  1. 맥에서 최신 `build_stats.json` 재집계 (윈도우 participants.jsonl 반영)
  2. 맥 → 파이 rsync: `chroma_db/`, `data/processed/`, `data/raw/ddragon/16.22.1/champion/` (recommend.py가 피해 유형 판단에 사용)
  3. 테스트: `streamlit run app.py --server.port 8510 --server.headless true` (첫 실행 시 임베딩 모델 약 500MB 다운로드)
  4. 터널 호스트 추가: 예 `lol.wooki.cloud` → `http://localhost:8510`
  5. systemd 등록 (`/etc/systemd/system/gamehikking.service`, Restart=always)
- 결정 필요: 시연 후에도 공개로 둘지
- Riot API 키는 앱 실행에 필요 없음 → 파이에 `.env` 불필요
